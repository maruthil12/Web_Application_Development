# IPL 2026 Ticket Booking Web Application

A responsive, interactive web application for browsing IPL 2026 match schedules, exploring participating teams and venues, and booking stadium tickets online.

## Features

* **Match Schedule & Ticket Pricing:** Browse upcoming IPL 2026 fixtures, dates, venues, and ticket pricing across **General**, **Premium**, and **VIP** stand categories.
* **Teams & Venues Showcase:** Highlights all 10 IPL franchises with team-color accents alongside major Indian cricket stadiums.
* **Interactive Ticket Booking:**
  * Client-side form validation for user details, match selection, stand category, and ticket quantity.
  * Ticket delivery options (E-Ticket vs. Stadium Box Office Pickup) and optional add-ons (Stadium Parking Pass, Official Team Jersey Combo).
  * Booking summary card and stadium entry guidelines.
* **Smooth User Experience:**
  * Smooth scrolling from match schedule **Book** buttons directly to the booking form.
  * Automatic match pre-selection based on the clicked schedule row.
  * Instant toast notifications for booking actions and confirmations.

## Technologies Used

* **HTML5** – Semantic structure and client-side form validation
* **CSS3** – Custom properties, Flexbox, CSS Grid, and responsive layouts
* **JavaScript (ES6+)** – DOM manipulation, event handling, and interactive UI feedback
* **React JS** – Component-based UI architecture
